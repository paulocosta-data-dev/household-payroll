# Instalador

Esta pasta irá conter o bootstrap Windows responsável por:

1. verificar os requisitos de WSL 2 e Docker Desktop;
2. instalar ou orientar a instalação dos pré-requisitos;
3. carregar a imagem versionada da aplicação;
4. criar volumes e configuração local;
5. configurar o arranque automático;
6. criar atalhos para atualizar, consultar e fazer backup.

O instalador não deve incluir dados pessoais nem credenciais.
